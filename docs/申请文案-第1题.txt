我构建了一个多模型中枢 Agent 平台（AI Chat Studio）。核心痛点是：开发者在日常开发中需要同时使用多家大模型 API，但每家的 Key 管理、用量追踪、限流策略各不相同，缺乏统一调度能力。

核心逻辑流：平台通过 OpenAI 兼容协议统一接入 6+ 家模型服务（小米大模型、硅基流动、DeepSeek、百度千帆、蚂蚁百宝箱、OpenAI），内建一个智能路由 Agent——它根据各 Key 的剩余额度、响应延迟和限流状态自动调度请求。当某个 Key 触发 429 限流时自动熔断并切换到下一个可用源，实现零人工干预的高可用推理。同时维护一个 Skill 知识库 Agent，用户可上传领域知识文件，自动注入系统提示词实现 RAG 增强。

目前在个人开发环境中持续使用，日均发起约 200 次推理请求，累计消耗 Token 超 5 亿，其中小米大模型通道承担了约 70% 的负载，将多模型切换效率从手动 5 分钟缩短到自动 0 秒。
